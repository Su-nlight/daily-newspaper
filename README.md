# Daily Signal — Module 01 Foundation

This repository contains the Module 01 foundation for a Next.js + TypeScript + Tailwind CSS app using the App Router.

## Available Scripts

- `npm run dev`
- `npm run lint`
- `npm run build`
- `npm run start`

## Scope

This module sets up:

- Route foundation for core product sections
- Shared domain types
- Centralized mock-backed API client
- Mock newspaper data separated from API layer
- Extendable folder structure for future modules
